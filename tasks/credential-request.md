# 先方への依頼文（6媒体の認証情報）

送るのはユーザー本人。「当方の Google アカウント」は送る前にどのアカウントにするか決めて書き換える。

件名: 収支分析・広告データ連携のための認証情報ご発行のお願い

いつもお世話になっております。

管理画面の「収支分析・広告データ管理」と「広告・ユーザー分析」の追加について、ご報告とお願いです。

認証情報がなくても作れる部分は先に作りました（本番への反映はこれから行います）。
- ダッシュボード：課金率・DAU・WAU・MAU・継続率・ARPU・ARPPU・ARPDAU（期間指定）
- 顧客分析：総ユーザー数・新規・退会・総ログイン数・登録の曜日×時間帯
- 広告データ管理：広告費・CPI・ROAS・ROI と、媒体ごとの取り込み状況

収益や広告費を使う指標（ARPU・ROAS など）は、各媒体をつないだ時点で数字が出ます。そのために、下記6つの認証情報のご発行をお願いできますでしょうか。

■1. App Store Connect（iOS の課金売上）
「ユーザとアクセス」→「統合」→「App Store Connect API」で、チームキーを1つ作成してください。アクセス権は「Sales」で足ります。
- Issuer ID
- キー ID
- 秘密鍵ファイル（.p8）※作成直後に一度しかダウンロードできません
- ベンダー番号（「支払いと財務レポート」画面の左上に表示されます）

■2. Google Play Console（Android の課金売上）
Play Console が毎日書き出している売上レポートを読み取ります。
- 読み取り用サービスアカウントの鍵（JSON ファイル）。Play Console の「ユーザーと権限」で、このアカウントに「財務データの表示」権限を付けてください
- レポートの保管先（「レポートのダウンロード」→「財務」画面にある gs://pubsite_prod_rev_ で始まる URI）
サービスアカウントの作成が難しければ、こちらで用意したアカウントのメールアドレスをお送りしますので、招待だけしていただく形でも構いません。

■3. Google AdMob（バナー広告の収益）
AdMob の API はサービスアカウントに対応していないため、Google アカウント単位での許可が必要です。
「設定」→「アクセスと承認」から、当方の Google アカウント（別途お知らせします）を、レポートを閲覧できる最小限の権限で追加してください。API の設定はこちらで行います。
あわせて、パブリッシャー ID（pub- で始まる番号。「設定」→「アカウント情報」に表示）をお知らせください。
同じ画面の「レポートのタイムゾーン」が日本時間になっているかもご確認ください（日本時間でないと、日別の収益が1日ずれて集計されてしまうためです）。

■4. AdGeneration（リワード広告の収益）
レポートを API で取得するためのキーと、Supership 様から案内されている API の仕様書（URL か PDF）をお送りください。発行に申請が必要な場合は窓口を教えていただければ、申請の文面はこちらで用意します。対象のリワード広告枠の ID もお願いします。

■5. SmaAD（オファーウォールの収益）
同じく、レポート取得用の API キー（またはトークン）と仕様書をお願いします。

■6. Tenjin（広告費・インストール数）
Tenjin の管理画面の API キー一覧から、レポート取得用の API キーをお願いします。
なお、広告費は Tenjin に各広告媒体を連携していないと取り込まれません。Tenjin の画面でキャンペーンごとの広告費が表示されているかも、あわせて教えてください。

■お渡しの方法
鍵ファイルや API キーは、メールやチャットの本文に直接貼らず、Google ドライブなどで当方だけに共有する形でお送りください。受け取った認証情報はサーバーの設定にだけ置き、画面やソースコードには載せません。

■仮で決めている点（違っていればお知らせください）
- インストールの曜日・時間帯は、端末ごとのインストール時刻が Tenjin の有料オプションのため、アプリの新規登録日時で代用しています
- 退会ユーザー数は、退会の記録を始めた日以降の件数です（これまでの退会は記録が残っていません）

■いただいた後の流れ
届いた媒体から順に取り込みを作り、各媒体の管理画面の数字と一致することを確かめてから本番に出します。取り込みは毎日11時と18時に自動で行い、直近7日分を取り直すため、速報値から確定値への差し替えにも追従します。

全部そろわなくても、届いたものから進めます。ご不明点があればお気軽にお知らせください。
何卒よろしくお願いいたします。
